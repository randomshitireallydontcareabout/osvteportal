Import CSV

Upload a CSV file. The importer recognises common columns such as Stock Code, MRS Ticket, Serial Number, Technician, Test End Time, Result, Part Type, WH Location, and more.

Notes
  • Importing is a merge operation. Existing rows are kept unless Clear existing tickets first is ticked.
  • The uploaded file must contain a tickets table (for .db) or a parsable CSV header row.
  • Column matching is case-sensitive against the current schema. Unknown columns are silently ignored.
